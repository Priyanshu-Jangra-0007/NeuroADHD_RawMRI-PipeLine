RECOMMENDED

Complete MRI session

Upload one ZIP containing a BIDS subject/session with 4D resting-state BOLD, its JSON sidecar, and 3D T1w MRI.

INDIVIDUAL FILES

MRI / fMRI files

Select BIDS-named NIfTI files and sidecars, or stage a DICOM series. BOLD and T1w must belong to the same session.

Use filenames ending in _bold.nii.gz and _T1w.nii.gz. DICOM conversion is not executed in this intake-only release.
