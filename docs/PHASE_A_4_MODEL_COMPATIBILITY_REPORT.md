## 1. Executive Summary & Audit Context

The downstream machine-learning inference engine evaluates resting-state functional connectivity patterns to predict exploratory ADHD classification probabilities. The historical model was trained and evaluated in the upstream **NeuroADHD_ModelBenchmark** project (`run_20261004_182318_final_locked`). 

Both the feature-transformation pipeline (`final_preprocessing_pipeline.joblib`) and the classification model (`final_model.joblib`) are **strictly frozen**. Under no circumstances may they be retrained, refitted, re-scaled, or tuned on validation, test, or pilot data.

This audit evaluates the numerical, mathematical, schema, and structural compatibility between the features generated by the **NeuroADHD RawMRI PoC V2** pipeline and the expectations of the frozen downstream model.

## 2. Feature Contract Specification & Verification

### 2.1 Authoritative 19,900-Edge Pairwise Upper-Triangle Contract
- **Number of CC200 Regions**: Exactly $N = 200$ parcels labeled $1, 2, \dots, 200$.
- **Edge Count**: Exactly $\frac{N(N - 1)}{2} = \frac{200 \times 199}{2} = 19,900$ unique undirected edges.
- **Matrix Extraction Index**: Strictly upper triangle with offset $k=1$ (`np.triu_indices(200, k=1)`).
- **Edge Traversal Order**: Row-major lexicographic order:
  $$\text{ROI\_001\_\_ROI\_002}, \text{ROI\_001\_\_ROI\_003}, \dots, \text{ROI\_001\_\_ROI\_200}, \text{ROI\_002\_\_ROI\_003}, \dots, \text{ROI\_199\_\_ROI\_200}$$
- **Verification Result**: Verified in `src/features/connectivity.py:get_feature_names()`. The 19,900 names generated by the raw pipeline are identical to `NeuroADHD/src/features/extract_cc200_connectivity.py`.

### 2.2 Mathematical Definition of Pearson Correlation & Fisher-$z$
1. **Zero-Mean Centering & Covariance**:
   Let $X \in \mathbb{R}^{T \times 200}$ denote the temporal signals across $T$ volumes ($T \ge 50$). The sample Pearson correlation matrix $R \in \mathbb{R}^{200 \times 200}$ is computed with `rowvar=False`.
2. **Symmetrization & Diagonal Fixation**:
   $$R_{\text{sym}} = \frac{R + R^T}{2}, \quad \operatorname{diag}(R_{\text{sym}}) = 1.0$$
3. **Singularity Prevention (Boundary Clipping)**:
   To prevent division by zero or infinite values in $\operatorname{arctanh}(r)$ when $|r| \to 1.0$:
   $$r_{\text{clipped}} = \operatorname{clip}(r_{ij}, -1.0 + \varepsilon, 1.0 - \varepsilon), \quad \varepsilon = 10^{-7}$$
4. **Fisher Transformation**:
   $$z_{ij} = \operatorname{arctanh}(r_{\text{clipped}}) = \frac{1}{2} \ln \left( \frac{1 + r_{\text{clipped}}}{1 - r_{\text{clipped}}} \right)$$
- **Verification Result**: `src/features/connectivity.py:compute_connectivity_vector()` implements this exact formulation. Output is guaranteed 1D `float64` array of shape `(19900,)`.

## 3. Downstream Preprocessing Pipeline Audit

The pre-fitted preprocessing pipeline (`final_preprocessing_pipeline.joblib`) is an instance of `sklearn.pipeline.Pipeline` with 4 sequential steps:

```text

  └─ Step 4: 'select'   ── SelectKBest(score_func=f_classif, k=100)

Output: 2D NumPy array of shape (1, 100)
```

### 3.1 Feature Names & Schema Behavior
- **Audit Finding**: In the historical training script, the pipeline was fitted directly on a 2D NumPy array $X$ (`shape: (114, 19900)` or `(133, 19900)`) rather than a pandas DataFrame with string column headers.
- **Implication**: `pipeline.named_steps["imputer"].feature_names_in_` is `None`.
- **Contract Requirement**: Downstream inference must pass raw features as a 2D NumPy array `X_raw = z_vector.reshape(1, -1)` (shape: `(1, 19900)`). Passing a DataFrame with mismatched column types is unnecessary and may raise scikit-learn feature name mismatch warnings if scikit-learn is updated.

## 6. Compatibility Findings & Blocking Status

### 6.1 Compatibility Strengths
1. **Mathematical Identity**: The 19,900 Fisher-$z$ connectivity features computed by `src/features/connectivity.py` are mathematically and index-wise identical to the historical extraction code.
2. **End-to-End Inference Verification**: Passing the synthetic `roi_CC200.csv` generated by our pipeline directly into `predict_single_subject()` executed without error, successfully transforming $(1, 19900) \to (1, 100)$ and computing valid class probabilities:
   - Output: `P(Control) = 0.5846`, `P(ADHD) = 0.4154` (Predicted Class: 0).
3. **No Leakage**: The inference path is strictly transform-only; zero fitting occurs.

### 6.2 Key Audit Finding / Blocking Dependency
- **Finding**: While the joblib model artifacts are present on the host filesystem under `down/NeuroADHD_ModelBenchmark`, they are **not committed to the `NeuroADHD_RawMRI-PipeLine` repository** (excluded by `.gitignore: *.joblib`).
- **Impact**: In a standalone container deployment or clean CI runner without external volume mounts, downstream inference cannot be executed locally within the container without mounting the model directory.
- **Classification**: **BLOCKING ISSUE FOR STANDALONE INFERENCE DEPLOYMENT**.
- **Remediation**: An authenticated artifact retrieval mechanism or designated read-only model mount volume (`/opt/neuro_adhd/models:ro`) must be established before conducting an integrated end-to-end pilot.
