## 5. Secure Container Deployment Strategy

- **Volume Mount Path**: `/opt/neuro_adhd/models:ro`
- **Security Policy**:
  - Strictly read-only (`:ro`).
  - Mandatory SHA-256 verification performed at load time; mismatched or corrupted files abort execution immediately.
  - Symlinks within model directories are rejected (`RuntimeError`).
  - Missing model directory or missing artifacts fails closed (`FileNotFoundError`).
  - No fallback, default, or mock models permitted in production deployment.
  - Automated pre-commit rules prevent committing `*.joblib` to git.
  - Zero credentials or tokens logged during model loading.
- **Script Support**: `scripts/docker_run_synthetic.sh` checks for `NEUROADHD_MODEL_DIR` and automatically mounts it as `/opt/neuro_adhd/models:ro`.
