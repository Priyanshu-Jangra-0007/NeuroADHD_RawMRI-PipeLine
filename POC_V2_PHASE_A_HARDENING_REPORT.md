## 2. Technical Remediation Details

### 2.1 Hardened Synthetic-Only Execution (scripts/run_poc_v2.py)
- **Elimination of Substring Heuristics**: Substrings such as `"synthetic"` in the subject ID are no longer accepted as proof of synthetic data origin.
- **Fail-Closed Security Architecture**: Any attempt to process real scans, bypass restrictions via `allow_real_scans=True`, or supply real participant indicators (`2344857`, `peking`, `kki`, `nyu`, `adhd200`, `control`, `abide`, `fcon`, `sub-001`, `sub-control01`) immediately raises a fatal `RuntimeError`.
- **Cryptographic Input Authentication**: Synthetic phantom sessions generated by `generate_synthetic_phantom_session()` generate a signed `synthetic_manifest.json` containing:
  - Magic identifier: `"NEUROADHD_SYNTHETIC_DATASET_V2"`
  - Target subject and session IDs
  - Creation timestamp (UTC)
  - Precomputed SHA-256 hashes for all input NIfTI and JSON files.
- `check_safety_guards()` parses this manifest, verifies the magic header, validates subject ID agreement, and re-computes SHA-256 digests on `bold_path` and `t1w_path`. If the manifest is absent, modified, or has mismatched file hashes, execution fails closed immediately.

### 2.2 Enforced Tissue-Mask Spatial Geometry (src/preprocessing/registration.py)
In `resample_mask_to_target()`:
- **Spatial Dimension Assertion**: Asserts that `mask_3d.shape[:3] == transform_map.domain_shape[:3]`.
- **Origin Translation Offset**: Compares `mask_3d.affine[:3, 3]` to domain origin with tolerance `1e-3` mm.
- **Voxel-Size Scaling**: Computes Euclidean column norms of rotation submatrices (`np.linalg.norm(affine[:3, :3], axis=0)`) and asserts isotropic/anisotropic resolution agreement.
- **Oblique Orientation / Rotation**: Normalizes column vectors by voxel size to derive pure rotation matrices and verifies directional alignment.
- **Domain Isolation**: Structural anatomical masks (eroded WM and CSF) strictly require T1w-to-MNI mapping (`syn_mapping`), where domain is structural T1w space. Passing a composed EPI-to-MNI mapping (whose domain is functional EPI space) is strictly rejected with a clear descriptive error.

### 2.3 Schema-Validated Provenance & Measurable Validation Gates (configs/provenance_schema.json)
- **Draft-7 Schema Conformance**: `scripts/run_poc_v2.py` enforces runtime validation of `provenance.json` using `jsonschema.validate()`. Provenance schema violations abort pipeline completion.
- **Measurable Gate Assertions**: Replaced static string placeholders with dynamic assertions:
  - `gate1_resources`: Verifies peak RSS memory against ceiling (`<= 2.5 GB`).
  - `gate2_bids_input`: Asserts TR > 0.0s, $T \ge 50$, positive spatial dimensions.
  - `gate3_atlas_grid`: Validates target reference grid dimensions.
  - `gate4_spatial_alignment`: Verifies resampled 4D BOLD spatial dimensions and affine match the target grid.
  - `gate5_roi_coverage`: Verifies exactly 200 non-zero parcels and 0 constant (zero-variance) parcels.
  - `gate6_feature_schema_conformance`: Verifies 19,900 finite float64 features and lexicographic ordering. Explicitly records `historical_concordance_assessed: false` and `historical_concordance_status: "NOT_ASSESSED"`.
- **Complete 12-Artifact Tracking**: Provenance and output manifest track all 12 output files with SHA-256 digests:
  1. `roi_csv` (`roi_CC200.csv`)
  2. `features_csv` (`features_19900_fisher_z.csv`)
  3. `features_npy` (`features_19900_fisher_z.npy`)
  4. `motion_tsv` (`motion_parameters.tsv`)
  5. `fd_tsv` (`framewise_displacement.tsv`)
  6. `confounds_tsv` (`confounds.tsv`)
  7. `confound_report_json` (`confound_report.json`)
  8. `qc_coreg_png` (`qc_registration_epi_to_t1w.png`)
  9. `qc_norm_png` (`qc_registration_t1w_to_mni.png`)
  10. `qc_tissue_png` (`qc_tissue_masks.png`)
  11. `qc_parcellation_png` (`qc_parcellation_cc200.png`)
  12. `provenance_json` (`provenance.json`)

### 2.4 Canonical CC200 Atlas Identity Verification (src/parcellation/extractor.py)
Implemented `verify_canonical_cc200_atlas()`:
- **Cryptographic Hash**: Asserts SHA-256 == `9467afce23ad7197fbbc8c96aadc8c0c2e36d4938445e3c1570a5deac489c650`.
- **Grid Dimensions**: Exactly `(63, 75, 61)`.
- **Voxel Zooms**: Exactly `(3.0, 3.0, 3.0)` mm.
- **Reference Affine Matrix**: Matches canonical MNI152 3mm grid:
  $$\begin{bmatrix} -3 & 0 & 0 & 93 \\ 0 & 3 & 0 & -129 \\ 0 & 0 & 3 & -72 \\ 0 & 0 & 0 & 1 \end{bmatrix}$$
- **Parcel Labels**: Exactly 200 contiguous integers $1 \dots 200$.

## 4. Remaining Blockers Before Real MRI Execution

Processing of real participant MRI data remains strictly prohibited until the following prerequisites are completed:
1. **Formal Code Review Signoff**: Independent acceptance review of Phase A remediation and safety guard implementation.
2. **Authorized Developmental Phase B Plan**: Agreement on single-subject dry-run protocol on non-sensitive developmental training data.
3. **Canonical Atlas Path Provisioning**: Verified local mounting of `data/atlases/cc200_roi_atlas.nii.gz` with verified SHA-256 digest on deployment infrastructure.
4. **Environment Isolation**: Confirmation that real-scan executions run within sandboxed, non-privileged containers with enforced 2.5 GB memory limits.
