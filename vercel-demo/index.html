The research workflow

How the data path is designed

The intended path connects BIDS-organized MRI inputs to CC200 time series, functional-connectivity features, and a downstream research classifier.

01 / INPUT

Resting-state BOLD

4D fMRI data with spatial dimensions and a time axis, organized using BIDS naming.

02 / INTAKE

Structure checks

Local intake validates NIfTI dimensions, BOLD metadata and session consistency.

03 / PROCESS

Preprocessing

Research design covers motion, normalization, confounds and temporal filtering.

04 / ATLAS

CC200 extraction

Mean BOLD signal is intended to be extracted for 200 atlas regions.

05 / FEATURES

Connectivity

200 regions yield 19,900 unique pairwise correlations, transformed with Fisher z.

06 / MODEL

Research inference

A downstream pipeline selects 100 features before its frozen Random Forest model.
